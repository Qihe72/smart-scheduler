# 演示提纲（PPT + 视频脚本）

> 配套文件：`README.md`（文字材料）、`docs/images/`（截图）
> 目标：3 分钟内让评委看懂**想法 — 实现 — 问题解决过程**

## 一、PPT 结构（建议 12 页）

| 页 | 标题 | 讲什么 |
|---|---|---|
| 1 | 封面 | 项目名 / 姓名 / 学号 / 一句话介绍 |
| 2 | 我遇到的真问题 | 用"手机日历加一件事要 30 秒""待办 App 没有时间轴""课程表 App 不管 DDL"讲痛点（**讲自己的真实使用**，别讲泛泛的"现代人很忙"） |
| 3 | 我的定位 | 一句话：自然语言 → AI 解析 → 落到课表。三个关键设计：**节次不是上下午 / 结果要人工确认 / 数据留本地** |
| 4 | 现场演示 1 | 自然语言 → 确认卡片 → 写进课表（截图或录屏） |
| 5 | 现场演示 2 | 节次课表：连堂课合并单元格、今天高亮、已结束课程淡显 |
| 6 | 现场演示 3 | 导入自己的课表：一份 `.ics` → 16 门课，双周课自动合并，学期起点与作息自动校准 |
| 7 | 设计取舍（1） | **为什么让 Python 算日期、不让 AI 推**（日期参考表 + 动态 few-shot，实测三条全对） |
| 8 | 设计取舍（2） | **为什么 AI 结果要逐条确认**（AI 会算错，落盘前必须过一眼） |
| 9 | 设计取舍（3） | **为什么"已结课"是实时算的**（否则"一键清空已完成"会删掉整学期课表）—— 这页最能体现"想过后果" |
| 10 | 问题解决过程（重点） | 挑 3 个最有代表性的：`WakeUp .ics 把双周课拆成 6 条` / `VALARM 覆盖课程描述` / `BOM 导致静默读空`。每个都用"现象→定位→根因→修复→验证"讲 |
| 11 | 我怎么验证它真能用 | AppTest 在真实 Streamlit 运行时跑 + 真实课表端到端 + 数据 SHA256 比对 + 真启动 health 200 |
| 12 | 后续计划 / Q&A | 云端部署、空档推荐、周报复盘 |

## 二、视频脚本（约 3 分钟，逐镜头）

| 时间 | 画面 | 旁白要点 |
|---|---|---|
| 0:00-0:20 | 封面 + 痛点表格 | "作为一个大二学生，我的时间是一张按节次排的课表加一堆 DDL。但加一件事要 30 秒……" |
| 0:20-1:00 | **真实操作**：输入"明天下午三点开组会，这周五前交实验报告" → 点智能解析 → 出现两张确认卡片 → 改一下标题 → 确认添加 | 强调"AI 解析的结果**我先过一眼**才落盘"；顺手展示日期算得准（明天/这周五） |
| 1:00-1:30 | 切到周课表：显示连堂课占 3 格、今天的列高亮、已过的课标"已结束"；点"下周"翻页 | "时间刻度用的是**节次**，不是笼统的上午下午" |
| 1:30-2:10 | **导入自己的课表**：上传 `.ics` → 预览表（16 条）→ 看到"双周课合并"说明 → 点确认导入 → 课表立刻排满 | "这个文件里双周课被拆成了 6 条独立事件，我做了归并" |
| 2:10-2:40 | 屏幕展示源码 + 测试输出 | 挑一个问题的排查过程讲：现象（6 条重复）→ 打开 `.ics` 看 `UNTIL` → 根因（每次课被导出成只重复一次）→ 修复（按课程名+时间+地点归并，按周次推断单双周）→ 验证 |
| 2:40-3:00 | 手机画面 | "手机连同一 WiFi 就能用，还有专门为窄屏做的「今日」列表"；收尾 + 后续计划 |

**录制建议**：用 OBS 或 Win+G 录屏；**别剪辑掉操作过程**（评委想看真实可用）；视频控制在 3 分钟内，语速正常即可。

## 四、可能被问到的问题（准备好答）

| 问题 | 回答要点 |
|---|---|
| 为什么不用数据库？ | 单用户、数据量小（几十条）、本地优先；JSON 可读可备份可手动改。换数据库只是 `task_manager` 一层的事 |
| AI 算错日期怎么办？ | 两层防护：① 不让它猜——Python 先把"日期参考表 + 示例"喂进去；② 结果必须逐条人工确认才落盘 |
| 数据隐私？ | 全部存在本机 JSON；只有自然语言解析那一步会把**你输入的那句话**发给 DeepSeek，其余功能不联网 |
| 为什么不做成小程序/App？ | 现在用手机浏览器 + 添加到主屏幕已够用；要走小程序需要重写前端 + 后端上云，属于后续计划。三层架构就是为了这个——`task_manager`/`importer`/`ai_parser` 能直接复用 |
| 最难的地方？ | 不是写 UI，是**真实数据里的坑**：WakeUp 导出的 ICS 把双周课拆成多条、VALARM 覆盖描述、UTC 的 UNTIL。这些只有拿自己的课表跑才会暴露 |
| AI 帮你写了多少？你能改吗？ | 如实说：AI 主要帮实现和写测试；**取舍是我定的**，每个问题我都复现并验证过。可现场改 `config.py` 的作息表或学期设置演示 |
| 为什么课表要合并单元格？ | 三节连堂要一眼看出占三格；用真 HTML 表格 + `rowspan` 实现，而不是拼卡片 |
