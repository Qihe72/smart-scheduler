## 一、分镜脚本（约 4 分 30 秒）

**排序原则：把最有说服力的三处放在前面。** 评委的注意力在前 2 分钟最集中，
所以「一句话录入 → 自动排进课表」「拍一张课表照片 → 变成课表」「到期提醒 + 根因分析那张表」
这三件事必须在 3 分钟之内讲完，后面的内容都是补充。

### 🥇 镜头 1（0:00–0:50）：一句自然语言录入 → 自动排进课表

| | 内容 |
|---|---|
| **说什么** | "我的时间不是'几点开会'，是一张**按节次排的课表**加一堆 DDL。所以我要的不是又一个待办清单，而是**我说一句话，它变成课表上的一格**。" |
| **点什么** | ① 在小程序「任务」页点「AI 录入」；② 输入 `明天下午三点开组会，这周五前交实验报告`；③ 点解析；④ 出现两张确认卡片后，**改一下其中一条的标题**；⑤ 点「确认添加」 |
| **看什么** | 卡片上日期与时间算对了（"明天"、"这周五"）；**改完再确认**这一步要停一拍 —— 说清"AI 算错日期是常态，所以结果必须我过一眼才落盘"；回到课表页，那条日程已经排在对应节次的行上 |
| **为什么放第一** | 这是整个项目的场景起点。评委看完这一段就知道"这是什么、给谁用、凭什么比手机日历好" |

> **一句话锚点**："手机日历加一件事要填五个框、30 秒；我这里是一句话。"

### 🥈 镜头 2（0:50–1:50）：拍一张课表照片 → 变成课表

| | 内容 |
|---|---|
| **说什么** | "学期初最烦的是把课表录进去。现在**直接拍张照**就行。" |
| **点什么** | ① 「我的」→ 拍照识别课表；② 拍/选一张课表截图；③ 等返回候选课程；④ **勾选**几门；⑤ 点「替换课表」 |
| **看什么** | 识别出的课程列表；勾选后课表页立刻排满 |
| **这里要讲的一个"设计上的拒绝"** | 如果你把模型设成项目默认的纯文本模型点识图，它会**一个请求都不发就拦下来**并提示换模型 —— 因为拿纯文本模型传图"必然是白跑一次 + 一句看不懂的错"。**主动拦下比让它失败了再报错更省用户的钱**。模型的完整三态判定见 `README.md` 第 8.1 节 |
| **顺带一句边界** | "这条路**真实模型调用还没验证过** —— 本机没有可用的 Key。我验证到的是入参出参契约那一层。"（**照实说，别含糊**） |

### 🥉 镜头 3（1:50–3:00）：到期提醒 + **根因分析那张表**（最硬的一段）

| | 内容 |
|---|---|
| **说什么** | "前面的问题里，有一条我**不是靠读代码看出来的**，是靠**用真实数据反推**出来的。这是我这一轮花时间最多、也最想说的一段。" |
| **点什么** | ① 先演示到期提醒：打开提醒开关 → 授权 → 造一条 5 分钟后到期的截止 → 等定时器 → 手机收到服务通知；② 然后切到 `README.md` 第 8.1 节，**把那张对照表投出来** |
| **看什么** | 那张表：同一份真实数据、同一个定位函数，**默认作息 vs 校准作息，3 条任务 3 条结论都不同** |
| **怎么讲**（30 秒讲完"现象→定位→根因"） | **现象**：用户报"课程时间与导入文件不符""子任务与截止在时间表里看不到"。<br>**定位**：拿 Web 版数据库里同一份真实数据，用课表页真正在用的那个函数跑两遍 —— 一遍默认作息、一遍导入时校准出的作息。<br>**结果**：`12:00` 的截止在默认作息里落在 11:40–14:00 的午休空档、**任何一节都落不进去**，于是掉进「其他时段」；校准作息下它应该在第 5 节（11:45–12:25）。另外两条子任务一个从第 7 节变第 9 节、一个从第 1 节变第 5 节。<br>**根因**：导入课表时**算出了**校准作息，但**从来没写回 `settings`** —— 于是课表页一直拿内置默认作息算"这个时间属于第几节"。**文件里的时间是对的，屏幕上的行号是错的。** |
| **为什么这段最值钱** | 它同时体现了评审要的"**主动分析**"和"**解决问题的过程**"：不是猜，是用真实数据把两种口径跑出**可对照的数字**，再顺着数字找到那行没写的代码 |

### 镜头 4（3:00–3:40）：占用提示 + "排版与统计各算一套"那类 bug

| | 内容 |
|---|---|
| **说什么** | "新建任务时它会告诉你这段时间已经被占了 —— 但**不拦着你保存**，因为你可能就是故意重叠。" |
| **点什么** | ① 新建一条任务，时间填成与已有课程重叠 → 红字出现；② 点「换到最近的空闲课节」→ 时间被换到某个**节次的开始时刻**；③ 把时间改成 `09:40–10:00`（紧接上一节课）→ 红字**不出现**（半开区间，首尾相接不算撞） |
| **看什么** | 红字文案里的真实条数；避让后卡片落在**与时间对得上**的行 |
| **接着讲 30 秒** | 顺带讲"排版与统计各算一套"这一类 bug **在本项目累计出现过四次**（空闲节数按卡片数算、连堂只画在起始行、截止被算成占一节课、卡片画在第 3 节却让第 3 节算空闲），最后统一到一个 `resolveSpan`。**同一件事两处口径不一致，是这类项目最隐蔽的一类错** |

### 镜头 5（3:40–4:20）：验证方式 —— **"你可以自己复跑"**

| | 内容 |
|---|---|
| **说什么** | "我不说'它能用'，我给你几条命令，你自己跑。" |
| **点什么** | 打开终端，现场跑（都是零依赖、不联网、不需要云环境）：<br>`node miniprogram/utils/tests/run.js` → **1912 / 1912**<br>`node miniprogram/cloudfunctions/_selftest.js` → **1027 / 1027**<br>`python tools/verify_ics_cross.py` → **13 项全过** |
| **看什么** | 全绿 + 退出码 0 |
| **要强调的一句** | 云函数自测跑在**内存假数据库**上，含**伪造 `_openid` 的越权用例**；跨语言核对是**同一份 `.ics` 同时喂给 Python 与 JS、逐字段比对** —— 两边各自的测试全绿**不能**证明两边一致，只有逐字段比对才算证据 |

### 镜头 6（4:20–4:35）：15 秒讲「已知边界」

| | 内容 |
|---|---|
| **说什么** | "最后 15 秒说**我没验证什么**，因为这比我说'都做完了'更有用。" |
| **要点**（快速念，不展开） | ① **真实智谱请求一次都没发过**（模型吃不吃 Base64 图片、吐不吐 JSON 都没验证）；② **真实订阅消息下发没验证**，尤其 `date4` 字段的写法要真机确认；③ **真机 wx API**（拍照、压缩、授权弹窗）没验证；④ **WXSS 渲染观感**没看过；⑤ **定时触发器与控制台配置**没验证；⑥ **小程序备案没完成**（体验版可用，正式上线需要） |
| **收尾一句** | "这些清单写在 `README.md` 第八节，一条都没藏。" |

> **总时长核对**：50 + 60 + 70 + 40 + 40 + 15 ≈ **4 分 35 秒**，落在 3–5 分钟区间内。

## 五、可能被问到的问题（准备好答）

| 问题 | 回答要点 |
|---|---|
| **你这一轮到底解决了什么？** | 四个真机反馈：课程时间与导入文件不符、子任务与截止不在时间表里、没有占用提示、新增拍照识课表。**前两个是同一个根因**：导入时算出了校准作息却没写回 `settings`。我用真实数据把两种作息各跑一遍，**3 条任务 3 条结论都不同**，顺着这个差异找到了那行漏写的代码 |
| **你怎么确定"根因"就是它，而不是碰巧改好了？** | 因为修法是**直接消除差异本身**（把校准作息落库），而不是绕过现象。验证方式是重放那张对照表：改完之后 `12:00` 的截止落在第 5 节，与校准作息一致。另外两条导入路径（替换 / 追加）都验了 —— 只修一条路是常见的漏 |
| 为什么"午休"那天的空闲节数是 **12** 而不是 13？ | 因为空档行**不计入**空闲节数。**这是正确值，不是掉了一节课** —— 用户第一次看到容易当成 bug，所以我们把它写进了文档 |
| 为什么把"其他时段"从表格末尾挪到第一行？ | 因为**真机上要滑到底才看得见**等于"看不见"。这是用户报的"子任务与截止不能在时间表里显示"的另一半 —— 根因修完之后，**可见性**还得单独修 |
| 为什么占用提示不阻断保存？ | 用户**可能就是故意重叠**（"我一边自习一边等快递"）。所以只提醒、不加二次确认 —— 加了会让"保存"变啰嗦 |
| 为什么截止（ddl）不算占用一段时间？ | 截止的语义是"**某个时刻之前必须完成**"。23:59 前要交报告，不代表 23:00–23:59 被占住了。同一个问题如果在编辑页和课表页给出相反答案，评审一眼就能看出是洞 —— 所以两边口径统一 |
| 为什么"换到最近的空闲课节"只落在**课节开始时刻**？ | 因为课表页按节次画格子。给出 `09:57` 这种课间时刻，卡片会被画到跟时间对不上的一行 —— 那就**回到了用户最早报的那个问题**。找不到整段空闲课节时宁可明说"今天没有"，也不给一个会画错行的建议 |
| 为什么提醒会"发不出去"？ | **一次性订阅的额度是消耗品**：用户授权一次只能发一条。这是**平台规则**不是 bug。长期订阅只对特定行业类目开放，个人主体申请不到 —— 所以**没有模板时的降级方案是小程序内提示**，不依赖微信通知 |
| 提醒发重复了吗？ | 没有。按 `due_key` **幂等**：同一个截止时刻只提醒一次。而且"已提醒"**只认成功记录** —— 如果失败也算，用户把模板字段改对之后这条就再也发不出来了 |
| 用户拒收了怎么办？ | 微信回 `43101` 时云函数**自动关掉该用户的提醒**（否则每 5 分钟白跑一次），用户下次进小程序重新授权即可恢复 |
| AI 算错日期怎么办？ | 两层防护：① 不让它猜 —— Python 先把"日期参考表 + 示例"喂进去；② 结果必须逐条人工确认才落盘 |
| 数据隐私？ | 三种情况：① 单机自用，数据在你自己电脑的 `data/*.json`；② 多用户版，数据在服务器的 `data/app.db`——**有链接的人就能看到那份日程**，界面上已写明"别放敏感信息"；③ 小程序版，数据在微信云数据库、按微信身份隔离。**只有用到 AI 的那一步**会把内容发给服务商；**课表截图会上传用于识别，但不落库、不进日志**。用户自填的 Key 不回传原文，只回掩码 `****abcd` |
| 为什么又做了小程序？ | 手机浏览器那条路要先连同一 WiFi、换设备还得靠空间码认人；而个人主体的**不能用 `web-view`**，没法把 Streamlit 套壳，所以把业务规则重写成云函数 + 小程序 |
| 两个前端会不会各写各的？ | 会走样的地方都被摁住了：`utils/` 里四个模块是从 Python 逐条移植的纯函数，不依赖 wx API，能直接用 node 跑单测；并且**随仓库提交了跨语言逐字段比对脚本**，评委可当场复跑。规则只有一份，改了 Python 就要同步改 JS 并跑这套测试 |
| 小程序现在能演示吗？ | 代码、单测与云函数自测**都能当场跑**；但**真机与云环境还没完全打通**，AI 的真实联网调用也没验证过。要现场演示得先按 `miniprogram/README.md` 部署一遍（云环境 + 模板 ID + 触发器） |
| 最难的地方？ | 不是写 UI，是**真实数据里的坑**：WakeUp 导出的 ICS 把双周课拆成多条、VALARM 覆盖描述、UTC 的 UNTIL、以及本轮这个"作息算出来了却没落库"。这些只有**拿自己的课表跑 + 用真实数据反推**才会暴露 |
| AI 帮你写了多少？你能改吗？ | 如实说：AI 主要帮实现和写测试；**取舍是我定的**，每个问题我都复现并验证过。可现场改 `config.py` 的作息表或学期设置演示 |
| 为什么课表要合并单元格？ | 三节连堂要一眼看出占三格；用真 HTML 表格 + `rowspan` 实现，而不是拼卡片 |
