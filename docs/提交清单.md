## 四、上传到 GitHub 的步骤

在项目目录 `C:\Users\qihe\Desktop\日程安排\smart-scheduler` 打开终端：

```bash
git init
git add .
git status                 # ← 关键：确认没把 .env 和 data/*.json 加进去
git commit -m "智能日程管家：自然语言驱动的课表式日程管理"
git branch -M main
git remote add origin https://github.com/<你的用户名>/smart-scheduler.git
git push -u origin main
```

### ⚠️ 上传前必须确认（安全）

| 文件 | 为什么不能传 | `.gitignore` 是否已排除 |
|---|---|---|
| `.env` | **里面有你的 DeepSeek API Key，泄露会被盗刷** | ✅ |
| `data/schedules.json` | 你的真实课表、作业、DDL | ✅ |
| `data/settings.json` | 你的学期设置 | ✅ |
| `*.ics` | 你从 WakeUp 导出的课表原文 | ✅ |

`git status` 的输出里如果看到上面任何一个，**先停下来**，检查 `.gitignore`。

建议再加一个 `LICENSE`（MIT）：GitHub 新建仓库时可以直接选，或本地新建文件。
