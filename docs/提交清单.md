## 四、上传到 GitHub 的步骤

```bash
git init
```

### ⚠️ 上传前必须确认（安全）

| 文件 | 为什么不能传 | `.gitignore` 是否已排除 |
|---|---|---|
| `.env` | **里面有你的 DeepSeek API Key，泄露会被盗刷** | ✅ |
| `data/schedules.json` | 你的真实课表、作业、DDL | ✅ |
| `data/settings.json` | 你的学期设置 | ✅ |
| `*.ics` | 你从 WakeUp 导出的课表原文 | ✅ |
| `data/app.db`（多用户版的 SQLite） | 里面是你和同学的真实日程 | ✅ |
| 小程序里的 API Key | **不该存在**：Key 只放云函数环境变量，或由用户自己在「我的 → AI 设置」里填 | 不适用（代码里没有） |
